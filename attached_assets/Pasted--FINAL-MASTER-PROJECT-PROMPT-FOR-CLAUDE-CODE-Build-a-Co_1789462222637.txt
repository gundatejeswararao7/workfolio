# FINAL MASTER PROJECT PROMPT FOR CLAUDE CODE

## Build a Complete Unified Professional Social Network + Work Marketplace

You are an expert full-stack software architect, UI/UX designer, frontend engineer, Python backend engineer, database architect, security engineer, and AI workflow engineer.

Build this project as a **complete, functional, production-quality web application**.

This is NOT a static UI prototype.

Every important feature must work end-to-end:

```text
Frontend
   ↓
API
   ↓
Python Backend
   ↓
SQLite3
   ↓
Persistent Data
```

The application combines:

```text
Professional Social Network
+
Social Feed
+
People Discovery
+
Work Marketplace
+
Project Management
+
Chat
+
Notifications
+
Demo Wallet
+
AI Assistant
```

The most important architectural principle is:

> **ONE USER, ONE PROFILE, MULTIPLE CONTEXTS.**

There must NOT be permanent Employer and Worker roles.

A user can give work to another person and later take work from another person.

# 6. DYNAMIC ROLE LOOP

Example:

```text
USER A
  ↓
Creates Work
  ↓
REQUESTER
  ↓
User B accepts
  ↓
User B = ASSIGNEE
```

Later:

```text
USER B
  ↓
Creates another Work
  ↓
USER B = REQUESTER

USER A
  ↓
Accepts
  ↓
USER A = ASSIGNEE
```

Therefore:

```text
User
 ↓
Requester
 ↓
User
 ↓
Assignee
 ↓
User
 ↓
Requester
 ↓
...
```

The user's account and profile never change.

Only the context changes.

# 30. WHAT HAPPENS IF THE DEADLINE PASSES?

If the assignee has not submitted by the deadline:

```text
IN_PROGRESS
     ↓
DEADLINE PASSED
     ↓
OVERDUE
```

Do NOT automatically delete the work.

Do NOT automatically remove the assignee.

Do NOT automatically transfer it to somebody else.

Instead:

```text
Mark OVERDUE
Notify requester
Notify assignee
Show overdue duration
Allow assignee to submit
Allow requester to extend
Allow requester to cancel according to business rules
```
